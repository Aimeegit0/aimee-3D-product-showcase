项目介绍

一个黑金质感的实时 3D 产品展示厅 ABOUT THE SHOWROOM

AIMEE 把不同品类的产品放进同一套视觉语言里：枪械涂装、刀械皮肤与数码设备，都用同一块黑色展台、同一束金色轮廓光来呈现。目标不是做电商货架，而是让每件展品在网页里有被“端详”的机会。

01 / COLLECTION

分类展陈

枪械、刀械、数码三个系列，每个系列有独立的分类页，统一从产品数据生成卡片与缩略图。

02 / REALTIME 3D

实时渲染

基于 Three.js 的实时场景，PBR 金属材质配合自绘环境反射，旋转时能看到高光在表面流动。

03 / EXPLODE

结构拆解

每件模型都由独立零件组成，点击“拆解模型”即可平滑展开，观察机匣、刀身、屏幕等结构。

技术实现

全部页面为静态 HTML / CSS / JavaScript，无需构建工具即可直接打开。3D 依赖已本地化，断网也能正常渲染。模型使用程序化几何体（Box、Cylinder、Extrude、Capsule）搭建，屏幕与键盘纹理由 Canvas 动态生成，不依赖任何外部图片。

操作指南

  • 旋转在 3D 展示页按住左键拖拽，从任意角度观察产品。
  • 缩放滚动滚轮拉近拉远，查看刀身纹理或屏幕细节。
  • 拆解点击底部“拆解模型”，零件会平滑分离；再次点击复原。
  • 复位双击画面或点击“重置视角”，回到初始机位。
  • 自动旋转默认开启，点击按钮可暂停，方便细看某一面。
  • 切换在“产品图集”或“规格文档”中选择其他展品。
